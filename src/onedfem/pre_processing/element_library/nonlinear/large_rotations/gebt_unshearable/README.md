# Unshearable GEBT

`GEBTUnshearableBeamElement3D` is a 12-DOF Kirchhoff beam: Battini chord map
`p(U)` (stretch and local nodal rotations) with the linear Euler–Bernoulli
section stiffness. It is **not** a Total Lagrangian Euler–Bernoulli alias.

Shear-deformable GEBT remains the separate `GeometricallyExactShearDeformableBeam3D` type.
