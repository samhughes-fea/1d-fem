# Proofs

Formulation-specific proofs are organised by element type:

- **[euler_bernoulli/](euler_bernoulli/)** — Euler–Bernoulli beam
- **[timoshenko/](timoshenko/)** — Timoshenko beam (shear-deformable)
- **[levinson/](levinson/)** — Reddy and Levinson third-order shear beams
- **[benscoter/](benscoter/)** — Benscoter restrained warping (exact restrained torsion)
- **[gbt/](gbt/)** — cross-section modes (single-mode cantilever)
- **[section/](section/)** — anisotropic thin-walled section analysis (wall condensation, Saint-Venant problem)

Cross-formulation comparison is covered by parallel proofs in the relevant formulation folders (e.g. shear force from constitutive law: EB vs T).
